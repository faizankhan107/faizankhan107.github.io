# faizankhan107.github.io

Personal site for Muhammad Faizan Khan — PhD researcher, Faculty of Electronics and Information Technology, Xi'an Jiaotong University.

Single static page. No build step, no dependencies.

## Files

| File | Purpose |
|---|---|
| `index.html` | The whole site — HTML, CSS and the hero SVG inline |
| `Muhammad_Faizan_Khan_CV.pdf` | Linked by the "Download CV" button. Add this file yourself |

## Publish on GitHub Pages

1. Create a repository named exactly `faizankhan107.github.io` (it must match the GitHub username).
2. Upload `index.html`, this `README.md`, and the CV PDF to the repository root.
3. Settings → Pages → Source: `main` branch, folder `/ (root)`.
4. The site goes live at `https://faizankhan107.github.io` within a minute or two.

## Before publishing, replace

- The GitHub username, if it is not `faizankhan107`.

## Editing

Open `index.html` in any editor. Colours, fonts and spacing are CSS custom properties in the `:root` block at the top. Each content section is a `<section>` with an `id`; add or remove one without touching anything else.
